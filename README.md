# DLL++ Programming Language

Мощный, быстрый, модульный язык программирования с автообновлением библиотек и поддержкой ботов.

## 🚀 Быстрый старт
1.  Скачай установщик: [DLL++_Setup.exe](https://github.com/tomiemori222-hub/DLL-PLUS-PLUS-installer/raw/main/DLL++_Setup.exe)
2.  Установи программу (не забудь поставить галочку "Добавить в PATH").
3.  Открой новое окно командной строки и введи `dlat`.

## ✨ Основные возможности
*   **14+ встроенных модулей:** Аудио, графика, GUI, сеть, боты, ИИ.
*   **Автообновление библиотек:** Библиотеки обновляются сами с сервера.
*   **Мощная математика:** Калькулятор с функциями, градусами и переменными.
*   **Свои символы-активаторы:** `!`, `?`, `*`, `~` и другие для управления.
*   **Запуск скриптов:** `dlat script.dlat` в любой командной строке.

## 📖 Твой первый скрипт
Создай файл `hello.dlat` и вставь туда код:

dll}bat{=2=msg=Привет, мир!;1

Запусти его:
```bash
dlat hello.dlat
